ch16-more

lambda 表达式 / 列表推导式。

本页共 2 个示例文件（完整源码如下）。

lamba.py
# -*-- coding: UTF-8 --*-
#!/usr/bin/python
# Filename: lambda.py

def make_repeater(n):
	return lambda s: s*n

twice = make_repeater(2)

print(twice('word'))
print(twice(5))
list_comprehension.py
# -*-- coding: UTF-8 --*-
#!/usr/bin/python
# Filename: list_comprehension.py

listone = [2,3,4]
listtwo = [2*i for i in listone if i > 2]
print(listtwo)
